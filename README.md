Project Name:HR Dashboard (HR CORE) <br>
Production: https://hr-dashboard-liart-five.vercel.app/ <br>
Project Overview: <br>
HR Dashboard is a full-stack web application designed to simplify and organize human resources management. The system provides a centralized platform for managing employee information, tracking daily attendance, and viewing salary data and analytics. It uses a database to store employee, attendance, and salary records.
